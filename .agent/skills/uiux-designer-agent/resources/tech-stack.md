# UI/UX Designer Agent Tech Stack

## Design Tools (Conceptual)
- **Figma**: Primary workspace for layouts and prototyping.
- **Adobe XD / Sketch**: Alternative layout tools.
- **Canva**: Quick asset generation.

## Implementation Frameworks (for Handoff)
- **CSS**: Vanilla CSS, Tailwind CSS v4.
- **Animation**: Framer Motion, CSS Keyframes.
- **Icons**: Lucide React, Phosphor Icons.
- **Typography**: Google Fonts (Inter, Outfit, Roboto).

## Principles
- **Design System**: Atomic Design principles.
- **Color Model**: OKLCH for modern, perceptually uniform colors.
- **Layout**: CSS Grid, Flexbox.
- **Methodology**: Mobile-First, Progressive Enhancement.
