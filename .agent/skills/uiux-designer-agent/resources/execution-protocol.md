# UI/UX Design Execution Protocol

Follow these 4 stages for every design task.

## Stage 1: Discovery & Strategy (15%)
- **Objective**: Understand the project's unique footprint.
- **Steps**:
  1. Review requirements and core value proposition.
  2. Identify the project's industry (e.g., Enterprise, Creator Economy, E-commerce).
  3. Define the **Experience Strategy**: What should the user *feel*? (e.g., Secure & Trustworthy, Fast & Dangerous, Creative & Open).
  4. Perform a "Mood" audit of the chosen domain.

## Stage 2: Logical Foundation (25%)
- **Objective**: Establish information architecture and flow.
- **Steps**:
  1. Map the User Flow to the defined personality (e.g., Minimal steps for utility, Guided discovery for exploration).
  2. Define the Information Hierarchy based on task importance.
  3. Create structural wireframes that prioritize the project's unique features.

## Stage 3: Visual & Functional Formulation (45%)
- **Objective**: Synthesize the project's bespoke visual identity.
- **Steps**:
  1. Select Typography and Color Theory that match the Experience Strategy.
  2. Define the elevation and depth model (Flat, Neuromorphic, Glass, etc.).
  3. Create high-fidelity mockups that bring the synthesized style to life.
  4. Design interaction patterns that provide context-specific feedback.

## Stage 4: Verification & Handoff (15%)
- **Objective**: Ensure feasibility and quality.
- **Steps**:
  1. Run the UX Audit against industry-specific heuristics.
  2. Perform Accessibility check for the unique color/font selections.
  3. Prepare a **Style Manifest** for the Frontend Agent (CSS tokens, variables).
  4. Review against the `checklist.md`.
