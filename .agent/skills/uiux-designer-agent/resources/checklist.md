# UI/UX Design Checklist

## 1. Experience Strategy & Context
- [ ] **Contextual Fit**: Does the design style (colors, typography, density) reflect the project's industry and target audience?
- [ ] **Mood Alignment**: Does the interface evoke the intended emotion (e.g., trust, excitement, focus)?
- [ ] **User Goals**: Is the primary project-specific goal reachable with minimum cognitive load?

## 2. Visual Design & Style Formulation
- [ ] **Contrast**: Is the text-to-background contrast ratio at least 4.5:1 (WCAG AA)?
- [ ] **Hierarchy**: Is the primary action (CTA) the most prominent element on the page?
- [ ] **Consistency**: Are the synthesized project tokens applied consistently across all screens?
- [ ] **Alignment**: Is the layout following the selected grid system (e.g., 8px)?

## 2. User Experience
- [ ] **Intuition**: Can a first-time user understand the primary function within 5 seconds?
- [ ] **Steps**: Is the number of actions required to reach the goal minimized?
- [ ] **Feedback**: Do all buttons and links have hover/press states?
- [ ] **Errors**: Are error states designed with clear recovery instructions?
- [ ] **Empty States**: Are "no data" states designed to be helpful/encouraging?

## 3. Accessibility (A11y)
- [ ] **Touch Targets**: Are buttons at least 44x44px?
- [ ] **Color Blindness**: Is information conveyed via more than just color (e.g., icons + text)?
- [ ] **Legibility**: Is the minimum font size for body text 14px (preferably 16px)?

## 4. Technical Feasibility
- [ ] **Responsiveness**: is there a plan for how the layout adapts from Desktop to Mobile?
- [ ] **Complexity**: Are the proposed animations achievable with standard CSS/Framer Motion?
- [ ] **Assets**: Are images/icons optimized for web?
